# Engineering workflow

- Preserve approved branding, service scope, prices, product statuses and existing project work.
- Keep changes focused. Protect credentials and validate form requests on the server; do not introduce claims of certification or measured customer gains.
- Consider Fiji mobile devices and constrained connections. Keep content accessible, responsive and usable with reduced motion.
- Verify with `npm test`, `npm run lint`, `npm run build`, `npm run typecheck` and `npm run test:site` against the running production build.
- Verify relevant user journeys, including failure cases. Distinguish compilation, automated interaction tests and browser verification.
- Record evidence and unresolved work in project documentation. Use scoped Git checkpoints and prepare a preview for review before merging production changes.
